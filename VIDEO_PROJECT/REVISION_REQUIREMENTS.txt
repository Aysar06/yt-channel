# 7. EVERY CLIP MUST HAVE THE CORRECT LENGTH

There is NO universal clip duration.

Do not automatically cut clips to:

2 seconds
3 seconds
5 seconds
7 seconds
10 seconds

Inspect every clip.

Use it for exactly as long as needed for the viewer to understand the useful visual information.

Every shot should have:

A CLEAN ENTRY
A USEFUL MIDDLE
A CLEAN EXIT

Do not:

- enter too late
- leave before the important action finishes
- hold footage after the useful action is over
- artificially extend footage to match narration
- cut simply because a timer says so

EDIT AROUND VISUAL EVENTS, NOT ARBITRARY DURATIONS.

A great 10-second shot is better than five unrelated 2-second shots.

A 1.5-second shot is fine when that is genuinely all that is needed.

# 8. NO ACCIDENTAL LOOPING

Never loop footage simply because the narration is longer than the source clip.

PROHIBITED:

clip plays
→ reaches the end
→ jumps back to beginning
→ plays again

Also avoid:

- immediately replaying the same motion
- ping-ponging forward and backward
- reversing footage to extend it
- excessively slowing a clip to fill time
- freezing the last frame for several seconds
- repeating the same reaction/action twice without an intentional storytelling reason

If footage runs out:

- find another relevant clip
- use another angle
- use a screenshot
- use original evidence
- move into another related source
- create a relevant graphic
- rewrite the narration
- shorten the section
- rearrange the edit

Never make the viewer notice that the editor ran out of footage.

# 9. REMOVE CHOPPY EDITING

Fast pacing does NOT mean constant random cuts.

Good cut reasons:

- an action finishes
- narration moves to a new idea
- new evidence appears
- the viewer has absorbed the current visual
- a music beat supports it
- movement creates a natural match cut
- emphasis requires interruption
- pacing intentionally accelerates

Do not do:

1-second clip
CUT
1.5-second clip
CUT
2-second clip
CUT
1-second clip
CUT

for no reason.

If something interesting is happening, LET THE VIEWER WATCH IT.

Do not interrupt an important visual halfway through its action.

The timeline should feel fluid rather than machine-timed.

# 12. NATURAL PAUSES ARE NOT EMPTY SILENCE

- emotional impact
- joke timing
- suspense

Most ordinary sentences should flow directly into the next thought.

# FINAL NON-NEGOTIABLE PRINCIPLES

THE FINISHED VIDEO IS THE MASTER.

Not the original script.
Not the first voiceover.
Not the first storyboard.
Not the initial source list.

If changing an earlier decision improves the final video, change it.

Never force footage to fit arbitrary narration timing.

Never force narration to preserve a bad visual sequence.

Never loop footage because you ran out of material.

Never use unrelated media because it is convenient.

Never leave AI-style narration gaps.

Never use permanent decorative source bars.

Never rely on one repeated typography/layout template.

Never treat "natural pauses" as random silence.

Never hide quality problems in a production report instead of fixing them.

The final output should feel like a skilled human WRITER, NARRATOR, RESEARCHER, MOTION DESIGNER and VIDEO EDITOR worked together on one coherent production.

The goal is not:

"good enough for an AI-generated video."

The goal is:

"good enough that the viewer does not care or suspect how it was produced."
